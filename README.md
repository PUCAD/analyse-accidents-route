
# Analyse des accidents corporels de la route en France (2024)
Objectif

Identifier quels usagers sont les plus touchés par les accidents graves de la route en 2024, selon leur catégorie et leur âge.

Données
Source : Bases de données annuelles des accidents corporels de la circulation routière, ministère de l’Intérieur (ONISR), via data.gouv.fr.
Mise à jour du jeu de données : 29 décembre 2025.
Fichier utilisé : usagers-2024.csv, soit 125 187 usagers impliqués.
Méthode
Calcul de l’âge à partir de l’année de naissance (2 579 valeurs manquantes, environ 2 %, exclues de l’analyse par tranche d’âge).
Indicateur « grave » : usager tué ou blessé hospitalisé.
Comparaison des taux par catégorie d’usager et par tranche d’âge.
Test du chi-deux pour vérifier si l’écart entre catégories est statistiquement significatif.
Résultats
Piétons : 32,9 % sont tués ou hospitalisés, contre environ 16,5 % pour les conducteurs et les passagers.
Âge : la part de blessés graves est de 26,6 % chez les 60 ans et plus, contre 14,9 % chez les 25-39 ans.
Test du chi-deux : p < 0,001, l’écart entre catégories n’est pas dû au hasard.
Limites
Les résultats montrent une association, non une cause. Par exemple, les piétons sont exposés à des véhicules de nature différente, ce que ces données ne permettent pas de séparer.
La catégorie « blessé hospitalisé » n’est plus labellisée par l’autorité statistique depuis 2019 : les comparaisons avec les années antérieures doivent être prudentes.
Le fichier véhicules n’est pas encore croisé avec cette analyse.
